# AI StudyMate

**Your Personal AI Teacher. Anytime. Anywhere.**

AI StudyMate is an early-stage learning companion for school, college, and university students.

## First milestone: responsive web prototype

The repository now contains a responsive, mobile-friendly landing page and interactive study-question preview.

### Files

- `index.html` — page structure and content
- `styles.css` — responsive design for mobile and desktop
- `app.js` — interface interactions and prototype response

### Run the prototype

Open `index.html` in a browser, or publish the repository with GitHub Pages.

## Planned features

- AI tutor with step-by-step explanations
- Homework helper
- Notes and summaries
- PDF question answering
- Quizzes and mock tests
- Study planner and exam preparation
- Multilingual learning support, including Indian languages

## Current limitations

The question box is currently a UI preview. It does not yet call an AI model. A secure backend and AI API integration are required before real AI answers, accounts, file uploads, or saved study history can work.

## Development roadmap

1. Responsive web prototype
2. Secure backend and real AI tutor
3. Authentication and student profiles
4. Notes, quizzes, PDF chat, and study planner
5. Android app
6. Testing, accessibility, and deployment
